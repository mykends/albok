## 1.1 Variables and Expressions

A **variable** is a letter that stands for a number we do not know yet. An **expression** combines numbers, variables and operations.

- `3x + 2` is an expression with the variable `x`.
- If `x = 4`, the expression equals `3 · 4 + 2 = 14`.

### Try it

Evaluate `5a - 3` when `a = 2`.

## 1.2 Solving Linear Equations

An **equation** says two expressions are equal. To solve it, do the same operation on both sides until the variable is alone.

1. Start with `2x + 6 = 14`.
2. Subtract 6 from both sides: `2x = 8`.
3. Divide both sides by 2: `x = 4`.

> Always check your answer by substituting it back into the original equation.

## 1.3 Inequalities

Inequalities compare expressions using `<`, `>`, `≤` or `≥`. You solve them like equations, with one extra rule: when you multiply or divide both sides by a negative number, flip the inequality sign.

- `-2x > 6` becomes `x < -3`.

## 1.4 Introduction to Functions

A **function** assigns exactly one output to each input. We often write `f(x) = 2x + 1`.

- `f(0) = 1`
- `f(3) = 7`

Functions let us describe relationships, such as distance travelled over time.
